# Kenya Education Analysis 🇰🇪

Analysing Kenya's education crisis across 47 counties using Python and real data.

## What this project covers
- Primary and secondary school enrollment rates by county
- Dropout rates across all 47 Kenyan counties
- Teacher shortage analysis — pupil to teacher ratios
- Regional comparisons highlighting the most underserved communities

## Key Findings
- Average primary dropout rate: 19.7% — nearly 1 in 5 children
- Mandera has the highest dropout rate at 45.3%
- One teacher handles up to 79 students in the worst cases
- North Eastern Kenya shows the most critical education gaps

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
